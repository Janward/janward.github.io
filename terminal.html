Interactive Network Console (CLI)

Masukkan perintah terminal untuk berinteraksi langsung dengan database portofolio saya.

root@janward-server:~ ssh active (port 22)
Connecting to janward-alfredo.id [192.168.1.100] via SSH...
Connection Established. Welcome to Janward's Server Console v1.5.0!
